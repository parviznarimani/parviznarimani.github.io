# project3

Website version 3.3 · Last updated: October 2026

Editable fields for SkyWings®. Current progress: 10%. projectName.txt, projectStatus.txt, projectDescription.txt and projectProgress.txt feed the homepage project cards. Use 25–35 words for the description and an integer from 1 to 100, without %, for progress.

## Build and publish

From the website root, run `python3 build.py` after changes. Upload the changed sources and generated output, including sitemap.xml when page URLs change. The build runs locally; GitHub Pages serves the generated files.
