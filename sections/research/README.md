# research

Website version 3.3 · Last updated: October 2026

Homepage research section. Edit researchDirections.txt for the introduction, section.html for structure, and style.css for section styling. Descriptions support **bold** emphasis and are also loaded in the browser. Rebuild to refresh static HTML.

## Build and publish

From the website root, run `python3 build.py` after changes. Upload the changed sources and generated output, including sitemap.xml when page URLs change. The build runs locally; GitHub Pages serves the generated files.
